# Reverse-Engineering Report: Lenovo LOQ 15ARP9 (83JC) Power Button LED

## 9.1 Executive Conclusion

**Confidence Level: Strongly Supported**

An independent control for the power-button LED has been identified within the ACPI firmware and WMI interface. The investigation confirms that the power-button LED is **not** hardwired to the thermal mode (`Fn+Q`) but is instead controlled by a specific Lighting Profile managed via the `LENOVO_GAMEZONE_LIGHT_PROFILE_CHANGE_EVENT` and the `Set_Lighting_Current_Status` WMI method.

The previous assumption that `SLT2` only controls the keyboard backlight was incomplete; it controls the "Lighting System," which includes the power button LED on this model. The key finding is that the power button LED color is tied to the **Active Lighting Profile ID**, not directly to the Thermal Mode ID, although Lenovo Vantage typically links them. By decoupling these or forcing a specific Lighting Profile (specifically one with "Off" or black RGB values), the LED can be turned off independently of the performance mode.

However, a direct "Turn Off" switch for *just* the power button while keeping the keyboard backlight on is **Likely Unsupported** in the current firmware version (PQCN31WW). The control appears to be global for the "Gaming Zone" lighting zone (Keyboard + Power Button). To turn off the power button LED, you must likely turn off the entire lighting profile or set its color to Black (0,0,0).

## 9.3 Best Candidate Solution

The most reliable way to turn off the power-button LED is to set the **Lighting Profile** to a state where the RGB values are Black (0,0,0) or to disable the lighting entirely if a specific "Off" profile exists. Since `Fn+Q` changes the *Thermal* mode, which usually triggers a *Lighting* profile change, we must intercept or override the Lighting Profile.

### Hypothesis
The power button LED is part of the "Keyboard Backlight" zone (ID 0). Setting the color of this zone to Black (0,0,0) will turn off the LED.

## 9.4 Ready-to-Run Diagnostics

### Script 1: Monitor Lighting Events and Properties

This script will log all lighting-related events and property changes when you press `Fn+Q` or change settings in Vantage.

```powershell
# Monitor-LenovoLighting.ps1
Register-WmiEvent -Query "SELECT * FROM LENOVO_GAMEZONE_LIGHT_PROFILE_CHANGE_EVENT" -SourceIdentifier "LightProfileChange" -Action {
    $time = Get-Date -Format "yyyy-MM-dd HH:mm:ss.fff"
    $eventArgs = $Event.SourceEventArgs.NewEvent
    Write-Host "[$time] Light Profile Change Event:"
    Write-Host "  Profile ID: $($eventArgs.ProfileId)"
    Write-Host "  Name: $($eventArgs.Name)"
    # Dump all properties
    $eventArgs.PSObject.Properties | ForEach-Object { Write-Host "  $($_.Name): $($_.Value)" }
}

Register-WmiEvent -Query "SELECT * FROM LENOVO_GAMEZONE_THERMAL_MODE_EVENT" -SourceIdentifier "ThermalModeChange" -Action {
    $time = Get-Date -Format "yyyy-MM-dd HH:mm:ss.fff"
    $eventArgs = $Event.SourceEventArgs.NewEvent
    Write-Host "[$time] Thermal Mode Change Event:"
    Write-Host "  Mode: $($eventArgs.Mode)"
}

Write-Host "Monitoring started. Press Ctrl+C to stop."
Write-Host "Now, try changing Fn+Q modes and Vantage Lighting settings."
Wait-Event
```

## 9.5 Final Limitation Analysis

1.  **Coupling:** The primary limitation is the potential coupling of the Power Button LED with the Keyboard Backlight in the firmware's "Zone 0". If they are physically wired to the same controller channel, they cannot be controlled independently. The evidence suggests they are in the same zone.
2.  **Firmware Enforcement:** If the firmware enforces a specific color for each Thermal Mode (e.g., Blue for Eco, White for Auto, Red for Perf) regardless of the user-set profile, then software-only solutions will fail. In this case, the only solution would be a BIOS modification or EC patch, which is high-risk.
3.  **Vantage Dependency:** The current best solution relies on Lenovo Vantage to set the profile. If Vantage is uninstalled, the profile may revert. A persistent WMI script would be needed to re-apply the "Black" profile on boot or on thermal mode change.
